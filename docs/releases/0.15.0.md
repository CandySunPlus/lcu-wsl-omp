# LCU 0.15.0

**LCU now works with Grok CLI on macOS (experimental).**

## Changes

- **New experimental adapter: Grok CLI.** Run `lcu setup --agent grok` on macOS. Setup registers a user-scoped LCU plugin through Grok's own plugin manager; remove it with `grok plugin uninstall lcu-computer-use`. LCU's tool calls stay tied to the Grok prompt that started them, and a new prompt ends a turn that Grok closed without reporting it (cancel-and-send, rewind). Native app approvals appear as Grok's terminal form with the same choices as the original runtime. When Grok cannot show the form, the model is told to run `lcu apps allow <App>`; approving it with Touch ID or your password allows that app for every agent until `lcu apps revoke <App>`. Only Grok CLI 1.0.92 on macOS arm64 was tested live; see [Grok CLI](https://github.com/amontlabs/lcu/blob/main/docs/ADAPTERS.md#grok-cli) for the limits. ([#90](https://github.com/amontlabs/lcu/pull/90), thanks @Ivocin, who wrote the adapter)

## Upgrading

Run `lcu update`, then restart the agents that use LCU. To use Grok CLI, run `lcu setup --agent grok` after updating. To go back, reinstall 0.14.0.
